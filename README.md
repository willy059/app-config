# app-config

Dépôt de configuration statique, utilisé par certaines applications internes.

## Fonctionnement

Les applications concernées vérifient à leur lancement si un fichier précis
est présent à la racine de ce dépôt (publié via GitHub Pages). Sa présence ou
son absence détermine un comportement côté application.

Fichier concerné : `config.html`.
